GETTING STARTED

Workbench quick start

  1. Choose a reference target or enter RA and Dec in decimal degrees.
  2. Select survey and release, then choose Find observations.
  3. Use A/B buttons in Observation stack to compare two records.
  4. Choose Blink, Split or exploratory B − A. Or press + next to several records and use Sequence.
  5. Press Extract spectrum to build an exploratory spectrophotometry plot from many exposures.
  6. Toggle Gaia overlay to draw epoch-propagated reference stars on the image; arrows show proper motion (exaggerated).
  7. Use Evidence JSON to preserve source details and processing caveats.

Keyboard: Space starts/stops an available blink (outside form fields); Escape pauses playback; ? opens this help.

The interface contains no placeholder science measurements, fake epochs or fictional sky exposures.

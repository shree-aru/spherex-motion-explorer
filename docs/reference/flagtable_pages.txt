Input and Output DescriptionThe input to this module includes Level 1 photocurrent FITS images,
each with dimensions of 2,040×2,040 pixels in units of e −/s, and corresponding flag maps in FITS format
generated by the onboard SUR system for each of the six detectors. These flag maps are telemetered along
with the science data and share the same dimensionality as the science images. Additional inputs include
a 2,040×2,040 FITS map of permanently non-functional pixels for each of the six flight arrays, based on
pre-flight laboratory characterization, as well as flags set by the Correct Nonlinearity (Sect. 3.2.2), Update
Persistence Mask (Sect. 3.2.4), Create Source Mask (Sect. 3.2.9) and Outlier Pixel Detection (Sect. 3.2.10)
Level 2 modules.
The output comprises a per-exposure, per-detector bad pixel mask, delivered as a 2,040×2,040 FITS
image in which each pixel is annotated with a symbolic flag indicating its classification. Each flag corresponds
to a specific bit position, with standardized symbolic identifiers assigned to defined conditions. The full set
of flag names is recorded in the header of the associated spectral image output file (see, e.g, Table A.35 in
Sect. 2.2).

and publicly distributed through IRSA. IRSA’s visualization interface supports the display of these flags as
overlay layers, enabling users to assess pixel-level data quality interactively. Table 16 summarizes the flag

3.2.6 Dark Subtraction
Dark current (with units of e −/s) is estimated simultaneously with the flat-field response derivation, as
described in 4.2.1. This additive component is first subtracted from the 2,040×2,040 active pixel region of
the Level 1 image prior to applying the absolute gain matrix that converts to physical units.
3.2.7 Absolute Gain Correction
This processing step multiplies the dark current-subtracted 2,040×2,040 Level 1 image by the absolute
gain matrix, described in more detail in 4.1.1. The absolute gain matrix is a 2,040×2,040 array with
units (MJy/sr) / (e −/s). It encodes pixel-to-pixel response variations within spectral channels as well as the
absolute gain conversion for each spectral channel, such that multiplying it by the dark-subtracted Level 1
image brings the image to the physical unit of MJy/sr.
3.2.8 Astrometry
This processing unit refines the astrometric solution by determining the optimal translation, rotation, and
updated distortion map required to align detected stars in each of the six exposures with their counterparts
in the Reference Catalog. This correction ensures photometric accuracy at the sub-arcsecond level and
supersedes the coarse astrometry computed during Level 1 pipeline processing. The corresponding inputs
and outputs of this processing step are summarized in Table 17.
